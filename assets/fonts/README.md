Locura UI is a bitmap conversion of Lato Regular by Lukasz Dziedzic.
Source: https://github.com/google/fonts/tree/main/ofl/lato
The source font and generated atlas are distributed under the SIL Open Font
License in OFL.txt. The converted font uses the name Locura UI.

Regenerate from the project root with JDK 17 or newer:

    java tools/GenerateUiFont.java

The game loads the prebuilt atlas; AWT and font generation are development-only.
Glyphs are rasterized at 64 px and minified with mipmaps for smooth UI text.
